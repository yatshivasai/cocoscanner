# Security Policy

COCOSCANNER is an educational and investigative network tool. It is not a
replacement for a production SIEM or a guarantee that a network is safe.

## Reporting a vulnerability

Please do not publish sensitive capture files, credentials, or exploitable
proof-of-concept details in a public issue. Contact the repository maintainer
privately through the contact method listed on the GitHub repository profile
or repository page. Add a security contact before public release.

## Safe use

Only capture traffic and scan systems you own or are explicitly authorized to
assess. Treat imported PCAPs, logs, and indicator feeds as untrusted input.
